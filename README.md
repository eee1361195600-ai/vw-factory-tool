# vw-factory-tool

**Factory 多账号切号器 / 会话管理工具**

- Windows：`vwFactory.exe`（需 Windows 10/11 x64，系统自带 .NET Framework 4.8 即可）
- macOS：`vwFactory-osx-arm64.zip`（Apple Silicon）/ `vwFactory-osx-x64.zip`（Intel），自带运行时

两者都需要先安装 Factory 官方桌面客户端。

## 功能

### 多账号并行
- 一个账号一张卡片、一个独立的 Factory 窗口，多个账号可同时打开、互不干扰。
- 每个账号有独立的登录状态、会话记录和浏览器数据，不会串号。
- 网页登录完成后点「返回 Factory」，会准确回到发起登录的那个账号窗口。
- 同一邮箱不能重复添加。

### 额度与凭据
- 卡片显示各账号剩余额度，可在 Standard / Droid Core 两种视图切换。
- 一键刷新所有账号的额度和登录有效期；快过期时自动续期。
- 每小时自动「检测续接」：只对 2 小时内到期的账号续期；续期失败且已导入 Outlook 账号的会自动重新登录；其余静默跳过。顶部「检测续接」按钮可随时手动执行，状态栏显示结果汇总。

### 自动重新登录（Outlook 邮箱验证码，仅 Windows）
- 登录彻底失效时可自动重新登录：卡片右键「重新登录（自动接码）」，或在刷新额度失败时自动触发（同账号 30 分钟内最多一次）。
- 需要 `tools\factory_relogin.exe` 与 exe 同目录；首次使用会自动下载浏览器组件（约 150MB，存于 `tools\ms-playwright`）。
- 验证码从该账号的 Outlook 邮箱读取。Outlook 账号行格式：`email----password----client_id----refresh_token`（也接受 `:`、`|`、制表符分隔）。
  - 卡片右键「导入/覆盖 Outlook 账号…」保存，「复制 Outlook 账密+rt」可复制该行；卡片上「有rt / 无rt」表示是否已导入。
  - 「添加账号」时可直接粘贴 Outlook 账号行：名称默认取邮箱，保存后自动完成登录。只填邮箱则名称取邮箱、按普通方式手动登录。
  - Outlook 凭据加密保存在本机，仅当前 Windows 用户可读取；refresh_token 被微软轮换后会自动更新。
- 设置文件 `%LOCALAPPDATA%\vwFactory\relogin.json`（首次运行自动创建）可配置 `Proxy`（代理）和 `Headless`（是否隐藏浏览器窗口），留空使用默认值。

### 账号管理（卡片右键）
- 编辑名称、重新登录、导入 Outlook 账号。
- 删除账号：只移除卡片，**保留本机会话文件**（路径会在提示中给出）。之后用同一邮箱再登录会自动接续原来的会话记录。Factory 会话内容只保存在本机，手动删除目录后该会话将无法再打开；误删可从回收站还原。

### 会话中心（跨账号）
- 汇总本机所有账号的历史会话，支持搜索、只读预览。
- 重命名（同步云端标题）、删除（云端归档 + 本机文件移入回收站，可从回收站恢复）。两者都需要该账号处于登录状态。
- 生成「接续材料」，方便在别的会话或账号里继续。

### 卡片「▤ 会话」云端会话列表
- 列出该账号的全部云端会话，标注「本机可用」或「仅云端」。
- 右键：重命名、归档/删除、复制续接提示词。
- **克隆为本机新会话**：把「仅云端」的会话（在别的机器或已删除的环境里创建的）搬到本机，之后可直接打开继续对话。不调用模型、不消耗额度；原会话保留。
- **迁移到其他账号**：把会话搬到另一个账号下继续。默认迁移成功后删除原会话（可在确认框中取消勾选以保留）。两个账号都需已登录，目标账号需在本机打开过一次。
- 云端不保存的本地状态（如 todo 列表）不会随克隆/迁移带过去。

## 使用（Windows）

1. 下载 `vwFactory.exe`、`vwFactory.exe.config` 和 `tools\` 目录（自动接码需要）放到同一文件夹。
2. 双击运行，工具会检测本机 Factory 客户端。
3. 点击「添加账号」：填名称或邮箱 → 点击卡片，在弹出的官方页面完成登录；或粘贴 Outlook 账号行自动登录。
4. 再添加其他账号，点击各自卡片即可并行打开。

数据存放在 `%LOCALAPPDATA%\vwFactory\`。程序不会把任何凭据上传到第三方；网络访问包括 `api.factory.ai`（额度与云端会话）、自动接码时的 Factory 登录页与 Outlook 邮箱，以及首次下载浏览器组件。

## 使用（macOS）

1. 解压对应架构的 zip，把 `vwFactory.app` 拖到「应用程序」。
2. 应用未经公证：首次打开请右键 → 打开，或执行 `xattr -dr com.apple.quarantine vwFactory.app`。
3. 首次读取钥匙串中的 Factory 登录密钥时系统会弹窗，请选择「始终允许」。
4. 数据存放在 `~/Library/Application Support/vwFactory/`。

macOS 版已实测：检测 Factory、多账号并行、切回窗口、重命名/删除账号、会话中心、登录回调、移入废纸篓。暂未实测：额度刷新与云端会话操作、Intel 机型。macOS 版暂无自动接码。

## 说明与限制

- 云端会话的重命名 / 归档 / 克隆使用 Factory 客户端自身的接口，Factory 升级后可能失效。
- Factory 云端只有「归档」没有永久删除；本工具的「删除」= 云端归档 + 本机文件移入回收站。
- 卸载：结束程序后删除程序文件和 `%LOCALAPPDATA%\vwFactory\` 即可。
